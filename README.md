## 📖 About This Repository

This is where I work through machine learning ideas in code, from the maths to training models and seeing what they generate.

---

## 🚀 Key Implementations

* Deep Learning and Computer Vision: Dense and convolutional digit classifiers, plus a variational autoencoder that generates new digits.
* Transformers and Large Language Models: Music generation with a recurrent sequence model.
* RL post-training: an LLM judge turned into a reward for RLAIF plus classic RLHF ([notebook](Transformers_Large-Language-Models/3_RL_Post_Training.ipynb) · [open in Colab](https://colab.research.google.com/github/somilsin/Machine-Learning/blob/main/Transformers_Large-Language-Models/3_RL_Post_Training.ipynb)).
* TensorTonic Machine Learning Solutions: Vector operations and matrix transpose.

## 📊 Results and Notes

My saved vision run reached 97.38% test accuracy. The VAE reached a test loss of 152.60 nats per image after 10 CPU epochs. The face classifier's 99.76% figure comes from a sampled training batch.

The music and language adaptation notebooks also include smaller runs that fit my 4 GB GPU. Their settings and outputs are kept with each experiment.
